# Видача ОЗ (`basic_means`) — Odoo 19

Модуль обліку видачі основних засобів (ноутбуки, інструменти, техніка) співробітникам.

## Стандартний функціонал, який використано

| Потреба | Що використано |
|---|---|
| Довідник ОЗ (модель, серійний номер, категорія, вартість) | `maintenance.equipment` (модуль *Обслуговування*) |
| Співробітники, відділи, посади | `hr.employee` |
| Закріплення ОЗ за співробітником | стандартні поля `hr_maintenance`: `employee_id`, `equipment_assign_to`, `assign_date` |
| Історія змін, повідомлення, дії | `mail.thread`, `mail.activity.mixin` (чатер) |
| Нумерація актів | `ir.sequence` (`FA/<рік>/00001`) |
| Канбан / список / pivot / graph / activity, групування | стандартні в'ю і пошук |
| Друк акту | QWeb PDF-звіт на `web.external_layout` |

Новий документ лише один: **`basic.means.assignment`** (Видача ОЗ) — запис історії видачі.

## Як це відповідає завданню

1. **Внесення ОЗ на співробітника + кількість днів.** Документ видачі: ОЗ (модель, S/N, категорія підтягуються автоматично), співробітник (посада, відділ), відповідальний, дата видачі. Поле *Днів у користуванні* = від дати видачі до дати повернення (або до сьогодні).
2. **Історія видачі без одночасної видачі.** Одна й та сама техніка не може бути видана двічі одночасно:
   * перевірка при натисканні *Видано*;
   * Python-констрейнт: періоди використання одного ОЗ не перетинаються (навіть заднім числом);
   * частковий унікальний індекс у БД `UNIQUE (equipment_id) WHERE state = 'issued'` — захист від паралельних транзакцій.
   Видані/повернені записи не можна видалити — історія зберігається.
3. **Кнопки «Видано» і «Повернути»** — на формі/списку/канбані видачі та на формі обладнання. *Видано* закріплює ОЗ за співробітником (стандартні поля `hr_maintenance`), *Повернути* знімає закріплення (ОЗ — «На складі») і ставить дату повернення. На ОЗ показується статус *На складі / Видано*, поточна видача і smart-кнопка історії; на співробітнику — smart-кнопка виданих ОЗ.
4. **Канбан історії видачі** з групуванням по ОЗ та по співробітниках: меню *Обслуговування → Видача ОЗ → Історія за ОЗ / Історія за співробітниками* (також групування за категорією, відділом, статусом, датою в пошуку).
5. **Звіт «Акт видачі ОЗ»** — кнопка *Друк акту* або меню *Друк*. Акт для конкретного співробітника та ОЗ: реквізити компанії, номер і дата, ОЗ (модель, S/N, категорія, вартість), підписи сторін; для поверненого ОЗ — блок повернення.

## Встановлення

Залежність: `hr_maintenance` (тягне `hr`, `maintenance`).
Інтерфейс англійською, з повним українським перекладом (`i18n/uk.po`).
Меню: **Обслуговування → Видача ОЗ** (група *Менеджер обладнання*).

Права: менеджер обладнання — повний доступ; співробітник — лише читання власних видач.
